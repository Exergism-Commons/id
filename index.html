Exergism Commons Persistent Identifiers

id.exergism.org is the high-stability identifier surface for semantic resources published by Exergism Commons. Identifiers are intended to remain stable independently of repository layout, hosting provider, or user-facing websites.

Status: infrastructure bootstrap. Namespace reservations do not by themselves change the canonical identifiers of an existing project release. A project adopts an identifier namespace only through an explicit, versioned project change.

Reserved namespaces

  • https://id.exergism.org/exergism# — Exergism vocabulary namespace.
  • https://id.exergism.org/ecl# — reserved for ECL pending an explicit migration decision.

Ontology identifiers

  • https://id.exergism.org/ontology/exergism — Exergism ontology identifier and release-resolution surface.

Persistence contract

The rules governing allocation, immutability, redirects, namespace ownership and deprecation are documented in the repository's persistence policy.
